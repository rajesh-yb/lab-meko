# Meko hands-on labs

Meko is the shared memory, knowledge, and trace layer for AI agents — not the agent itself.

This repo holds labs that exercise those primitives with copy-paste prompts and sample files. You need a Meko account and the Meko MCP server connected in Cursor. See [docs.mekodata.ai](https://docs.mekodata.ai/).

Pick one story (both are ~90 minutes and the same Meko stations):

**[Fraud investigation copilot](labs/fraud-copilot/LAB.md)** — A payments-risk team uses one datapack so triage, investigation, and the next shift all work from the same playbook and prior cases.

**[YugabyteDB audit copilot](labs/yb-audit-copilot/README.md)** — A platform team triages YSQL audit alerts. Ten sample cases (HOLD / REVOKE / CLEAR). Start with the easy overview, then the step-by-step lab. Policy in the knowledge base, cluster quirks in memory, night-shift DBA resumes in a new chat.
